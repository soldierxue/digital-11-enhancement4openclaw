## 🎯 功能概述

监工虾是虾群写作系统的质量保证工具，负责：
1. ✅ 实时监控Phase 1-7执行质量
2. ✅ 主动发现问题（换话题、时效性评分错误等）
3. ✅ 生成详细的质量报告
4. ✅ 自动化质量检查流程

## 📊 输出报告

### 报告位置

执行后生成两个报告文件：

1. **JSON报告**：`memory/writing/supervisor-report-YYYY-MM-DD.json`
   - 机器可读格式
   - 包含详细的统计数据和问题列表

2. **Markdown报告**：`memory/writing/supervisor-report-YYYY-MM-DD.md`
   - 人类可读格式
   - 包含格式化的表格和说明

### 报告内容

#### 1. 执行概览
```
| 指标 | 数值 |
|------|------|
| 总问题数 | 42 |
| P0严重问题 | 20 |
| P1重要问题 | 0 |
| P2警告 | 22 |
```

#### 2. 各Phase统计
- Phase 1: 话题数、素材年份分布
- Phase 2: 文章数、字数异常
- Phase 4: v2文章数、换话题数
- Phase 5: 选出文章数、时效性评分准确性
- Phase 7: 发布文章数、Front Matter异常

#### 3. 问题详情
按优先级分类：
- **P0严重问题**：阻止发布（换话题、时效性评分错误）
- **P1重要问题**：需要修复（文章数量错误、评分异常）
- **P2警告**：可接受但需关注（字数偏差、标题变化）

## ⚠️ 问题等级定义

### P0 - 严重问题（阻止发布）
**影响**：违反核心规则，必须修复
**示例**：
- Phase 4换话题（薛以致用虾无权改变话题）
- Phase 5时效性评分错误（2024素材给满分）

**处理**：立即告警，阻止发布

### P1 - 重要问题（需要修复）
**影响**：影响质量，建议修复
**示例**：
- 文章数量错误（不足21篇）
- 2024素材总分>70
- Front Matter缺失

**处理**：记录在报告中，建议修复

### P2 - 警告（可接受但需关注）
**影响**：轻微问题，不影响发布
**示例**：
- 字数偏少/偏多
- 2024素材占比略高（>30%）
- 标题变化较大但未换话题

**处理**：记录在报告中，持续观察

## 📞 支持

### 问题反馈
如果监工虾检测到误报或漏报：
1. 检查脚本逻辑：`memory/writing/scripts/supervisor.js`
2. 调整相似度阈值（当前50%）
3. 更新检查规则

### 常见问题

**Q: 为什么所有v2都报告"换话题"？**
A: 可能相似度阈值太严格，检查v1和v2标题是否确实相似。

**Q: 如何跳过某些检查？**
A: 使用`--phases=`参数只检查特定Phase。

**Q: 报告太长怎么办？**
A: 查看JSON报告的summary部分，或只关注P0/P1问题。
